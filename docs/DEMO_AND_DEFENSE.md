# Демо и защита (сценарии для записи)

Видео нужно записать самостоятельно. Ниже готовый тайминг.

## Демо-видео 2–4 минуты

1. **0:00–0:20** — проблема: знания в файлах, опасно додумывать.  
2. **0:20–0:50** — вкладка «Документы»: показать витрину (после `seed_kb`) и открыть документ.  
3. **0:50–1:40** — вкладка «Вопросы»: спросить «До какого времени нужно провести стендап?» → ответ + источники.  
4. **1:40–2:30** — вопрос без данных: «Какой размер бонуса за лучший мем месяца?» → бейдж «требует проверки».  
5. **2:30–3:20** — вкладка «История»: фильтр review, карточка, audit_runs, экспорт JSON/CSV.  
6. **3:20–3:50** — коротко показать README/curl и `data/knowledge.db`.

## Защита 5–7 минут

1. Проблема и кому полезно.  
2. Контекст и ограничения (только веб-панель, SQLite, keyword-поиск).  
3. Архитектура: панель → API → БД → поиск → LLM JSON → quality → audit.  
4. Риски: галлюцинации, секреты, пустая база, формат JSON, воспроизводимость.  
5. План внедрения за 1 день.  
6. План развития.  
7. Мини-экономика из отчёта.

## Чеклист перед записью

- [ ] `python -m scripts.seed_kb`
- [ ] Успешный вопрос с источниками
- [ ] Вопрос с `needs_review=true`
- [ ] Видны audit_runs
- [ ] Экспорт скачивается
