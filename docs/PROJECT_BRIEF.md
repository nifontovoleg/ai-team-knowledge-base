# Постановка выпускного проекта

## Выбранный проект

Система знаний команды для службы поддержки интернет-магазина.

## Пользователи и материалы

Системой будет пользоваться служба поддержки интернет-магазина. В базе знаний будут храниться правила работы команды, частые вопросы клиентов, шаблоны ответов, словарь терминов и инструкции по обработке обращений.

## Проблема

Сотрудники поддержки тратят много времени на поиск информации и могут давать клиентам разные или ошибочные ответы.

## Решение

Веб-система ищет информацию во внутренних документах, формирует ответ с цитатами и назначает ручную проверку, если данных недостаточно.

## Результат

Оператор быстрее отвечает клиенту, видит источники ответа, а все вопросы, ошибки и проверки сохраняются в истории и аудите.

## Архитектура

Схема подготовлена в файле `docs/architecture.drawio`.

Основной поток:

`Веб-панель -> FastAPI -> SQLite -> Поиск -> LLM через ProxyAPI -> Контроль качества -> Аудит`

Если подходящих фрагментов нет, LLM не вызывается. Система возвращает безопасный ответ и устанавливает `needs_review=true`.
